Privacy by design

번역에 필요한 데이터만
사용자가 요청할 때 처리합니다.

VertaPane은 별도의 개발자 서버를 운영하지 않습니다. 실제 번역 요청은 사용자의 브라우저에서 사용자가 선택한 Amazon Bedrock 엔드포인트로 직접 전송됩니다. 여러 리전을 선택한 경우 요청 실패 시 다음 선택 리전으로 다시 전송될 수 있습니다.

처리 데이터 이용 목적 제3자 처리 보관·삭제 권한
01

처리하는 데이터

웹사이트 콘텐츠
사용자가 번역을 실행한 선택 문장, 현재 화면 또는 페이지의 표시 텍스트를 처리합니다. 사용자가 자동 번역 기능을 켠 경우 새로 표시되는 텍스트도 번역 요청에 포함될 수 있습니다.
Bedrock API 키
기본적으로 사용자가 입력한 키는 메모리에만 존재하는 세션 저장소에 보관하며, Chrome 종료 또는 확장 프로그램 재로드·업데이트·사용 중지 시 삭제됩니다.
설정에서 “이 기기에 키 저장”을 직접 켜면 브라우저를 다시 열어도 키를 쓸 수 있도록 이 기기의 로컬 저장소에도 함께 보관합니다. 이 저장소는 암호화되지 않으므로 해당 기기를 사용할 수 있는 사람이나 프로그램이 키를 읽을 수 있습니다.
이 설정은 기본값이 꺼짐이며 언제든 다시 끌 수 있고, 끄고 저장하면 기기에 저장된 키를 즉시 삭제합니다. 번역 기록에는 어느 경우에도 키를 저장하지 않습니다.
방문 URL과 페이지 제목
번역 기록 기능이 켜진 경우 기록 식별과 원문 다시 열기를 위해 현재 브라우저에 저장합니다. URL과 페이지 제목은 Bedrock 번역 요청에 포함하지 않습니다.
번역 기록과 페이지 스냅샷
선택·직접 입력 번역은 최근 100건, 사이트 번역 HTML은 최근 20건을 현재 브라우저에 보관할 수 있습니다. 페이지 스냅샷은 건당 최대 8MB입니다.
설정 정보
언어, 모델 ID, 선택한 AWS 리전 목록, 번역 스타일, 기록 사용 여부와 같은 환경설정을 현재 브라우저에 저장합니다.
02

데이터 이용 목적

데이터는 사용자가 요청한 번역 제공, 선택 번역 결과의 페이지 적용, 번역 기록 복원, 토큰·응답시간 표시와 설정 유지에만 사용합니다.

광고, 사용자 추적, 행동 프로파일링, 신용평가 또는 데이터 판매 목적으로 사용하지 않습니다.

03

외부 전송과 제3자 처리

사용자가 실제 번역을 실행하면 번역할 텍스트, 목표 언어, 원문 언어 설정과 문체 설정이 사용자가 선택한 AWS 리전의 Amazon Bedrock으로 HTTPS 전송됩니다. 여러 리전을 선택하면 오류 발생 시 다음 리전으로 동일한 번역 요청을 다시 보낼 수 있습니다. 인증을 위해 사용자가 입력한 API 키가 해당 요청의 Authorization 헤더에 사용됩니다.

Amazon Bedrock의 데이터 처리는 사용자의 AWS 계정 설정과 AWS 약관 및 개인정보 관련 정책의 적용을 받습니다. VertaPane 개발자는 번역 요청을 중계하는 별도 서버를 운영하지 않으며 데이터를 판매하거나 다른 제3자에게 제공하지 않습니다.

심사용 로컬 데모 모드에서는 번역 텍스트와 API 키가 외부로 전송되지 않습니다.

04

보관 기간과 삭제 방법

  • API 키 기본값: 현재 Chrome 세션 동안만 보관
  • “이 기기에 키 저장”을 켠 경우 API 키: 사용자가 끄거나 삭제할 때까지 이 기기에 보관
  • 선택·직접 입력·페이지 기록: 최근 100건까지 보관
  • 번역 페이지 스냅샷: 최근 20건, 건당 최대 8MB까지 보관

사이드바의 기록 화면에서 개별 기록 또는 전체 기록을 삭제할 수 있습니다. 설정에서 기록 저장을 끌 수 있으며, 데이터 처리 동의를 철회하고 저장하면 세션과 기기에 저장된 API 키가 모두 삭제되고 이후 외부 번역 요청이 차단됩니다. “이 기기에 키 저장”을 끄고 저장해도 기기에 저장된 키가 삭제됩니다. 확장 프로그램을 제거하면 Chrome이 해당 확장 프로그램의 로컬 저장 데이터를 삭제합니다.

05

브라우저 권한 사용

  • 웹사이트 접근: 사용자가 요청한 페이지의 표시 텍스트를 읽고 번역문을 적용하기 위해 사용
  • 저장소: 설정, 동의 상태와 선택적 번역 기록을 보관하기 위해 사용
  • 컨텍스트 메뉴: 선택 문장·전체 페이지 번역 명령을 제공하기 위해 사용
  • 사이드 패널: 번역 작업 공간과 기록 화면을 제공하기 위해 사용
  • 선택적 AWS 호스트 접근: 사용자가 선택한 Bedrock 리전들로 번역 요청을 보내고 오류 시 다음 리전으로 전환하기 위해 사용
06

Chrome 웹 스토어 제한적 사용

VertaPane의 사용자 데이터 사용은 확장 프로그램의 단일 목적인 웹페이지 번역 제공으로 제한됩니다. 사용자 데이터는 맞춤 광고, 데이터 판매, 대출·신용 판단 또는 본 기능과 무관한 목적으로 사용되지 않습니다.

07

방침 변경과 문의

데이터 처리 방식이 변경되면 이 문서의 시행일을 갱신하고 필요한 경우 확장 프로그램에서 다시 동의를 받습니다.

개인정보 관련 문의는 Chrome 웹 스토어의 VertaPane 등록 페이지에 표시된 개발자 지원 이메일을 이용해 주세요.
